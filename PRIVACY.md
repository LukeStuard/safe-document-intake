Privacy Notice

Safe Document Intake is a personal portfolio project. It is not a commercial product and is not offered to the public as a service.

What data it handles

The project processes synthetic data only. Every applicant, document, and name in it is generated by a script. It does not collect, store, or process information about real people.

Google account access

The app requests a single Google permission, drive.file, which lets it create and manage only the files it uploads itself. It cannot see, read, or change any other files in a Google Drive.

The only Google account connected to the app is the project owner's. The OAuth credentials and tokens are stored as encrypted secrets in the project owner's Cloudflare account and are never committed to this repository.

Third parties

Synthetic documents may be sent to AI model providers (Cloudflare Workers AI and Google Gemini) for automated review as part of the project's evaluation. Because the documents are synthetic, no personal information is shared.

Contact

Questions about this project can be raised as an issue on the GitHub repository.
